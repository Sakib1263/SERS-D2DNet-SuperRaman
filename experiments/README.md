# Optional studies

The copied PRISM-SERS LOCO/LOFO experiment is preserved locally with the original supplied folder. It is not a mandatory dependency of this package or its quick start.

Strict held-out chemistry studies, the five paper translation baselines, CNN/Self-ONN ablations, raw preprocessing ablations, SHAP, framework conversion, newer SuperONN operators, and joint training require separately identified protocols and their own validation. They are outside the first primary-pipeline release. Do not present a synthetic demonstration as a completed ablation or published-result reproduction.
